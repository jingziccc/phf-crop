# Interactive visualization

Install Jupyter and Matplotlib in the project environment. The notebooks use
the local data and models described in [Data and models](../DATA_AND_MODELS.md).

- [PHF-Crop trace notebook](mainline/phf_crop_visualization.ipynb) shows
  the localization trajectory and answers for a sample.
- [Fusion viewer notebook](mainline/phf_crop_loop_panels.ipynb) exports an
  interactive HTML view based on the [viewer template](mainline/fusion_web_template.html).

Notebook cells have been cleared of saved outputs. The notebooks generate
their own artifacts from local inputs.
